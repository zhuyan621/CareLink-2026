首页 `/?view=home#mapfm-architecture` 新增可点选的十智能体技术架构；支持切换护理交接、三年糖尿病、MedQuAD 三条路径，并查看每个模块的接收、产出、对应类与方法。交接工作台的工程桥也有返回架构区的入口。架构动画仅解释静态关系，实时状态仍以工作台每次响应为准。

## 一句话明确边界

任意医学问题**不能**被转换成任意疾病的患病概率。当前唯一已训练的前瞻结局是公开 NAGALA 队列上的**未来 3 年新发糖尿病**；模型需要明确的基线人群与五项数值。MedQuAD 是英文医学知识检索库，没有患者级未来发病标签，不能拿它的答案或相似度充当风险概率。TRIPOD+AI 要求明确预测结局、时间窗、目标人群、预测因子，并报告区分度、校准和适用性；这是本入口拒绝无依据百分比的依据之一：[BMJ TRIPOD+AI（2024）](https://www.bmj.com/content/385/bmj-2023-078378)。

## 实际路由

1. 对英文一般医学知识问题，调用本机 MedQuAD 检索，展示最多三条原始问题、答案和来源链接；无足够匹配时拒答。此路由不包含概率。
2. 对中文或英文的未来糖尿病风险问题，`medical_language.py` 只抽取用户明确写出的年龄、BMI（可由明确单位的身高体重计算）、基线空腹血糖、收缩压、甘油三酯，以及明确的“基线未患糖尿病”。支持常见同义写法、血糖和甘油三酯的 mg/dL→mmol/L 换算。出现缺项、冲突、单位不明、已患糖尿病或非三年时间窗时不调用模型。
3. 只有完整输入才通过原工程已接入的 `tfa.forecast_prospective` 运行 `mapfm_tfa_prospective_neural_v2` 检查点，并明确返回 `horizon_days=1095`、权重 SHA-256、`external_validation_completed=false` 和 `clinical_use_allowed=false`。超出训练队列观察范围由模型拒绝外推。研究估计仅用于演示，**不是已验证的个人临床概率**。
4. 对其他疾病的未来发生问题、中文一般知识问答及模型不可用状态，系统说明当前边界，不伪造答案或概率。中文一般知识问答尚未建立经过独立审核的来源检索通道。

合成示例：`未患糖尿病，50岁，BMI 25，空腹血糖5.3 mmol/L，收缩压125 mmHg，甘油三酯1.2 mmol/L。未来3年新发糖尿病的研究风险是多少？`。请只使用合成或充分脱敏内容，不输入真实姓名、电话、病历号；常见电话和邮箱格式会被接口拒绝，但格式检查不能替代人工脱敏。网页不保存本次自然语言输入。

## 泛化能力目前能说什么

自然语言解析的中英文改写、单位换算、缺失与冲突拒绝由 `tests/test_medical_language.py` 回归测试；这证明**输入适配的部分行为**，不证明疾病模型在新医院、新地区或中国养老人群仍准确。训练报告的 3 年结局可判定样本为 11,113 人、事件为 101 人，内部测试集事件仅 15 人。现有 AUROC 与内部校准都不能代替独立外部验证；项目目前没有可公开支持“泛化能力强”的跨队列性能估计。

下一步应预先登记独立的、具有授权的中国目标人群纵向队列，保持同一基线变量、糖尿病新发定义和三年观察窗，锁定模型后测区分度、校准曲线/斜率、Brier 分数、亚组表现与拒答/越界率，再考虑重校准。若要增加其他疾病，必须逐一取得相应纵向结局标签、训练、独立验证和人工安全审核；不能复用 MedQuAD 问答或把现有三年糖尿病数值改名。

## 核查入口

- `POST /mapfm/medical-language/evaluate`：请求 `{"question":"..."}`。返回 `kind`、提取字段、缺失/问题清单；只有 `kind=diabetes_3y_result` 才有 `estimate.research_probability`。英文来源问答返回 `kind=source_qa` 和 `qa.matches`，无 `estimate`。
- `GET /mapfm/prospective-neural/status`：核对训练结局、检查点和内部验证边界。
- `docs/MEDQUAD_BLIND_EVAL_20261014.md`：人工盲评流程；题包与原始评语不随公开交付包分发。
- `artifacts/prospective_neural/training_report.json`：原始研究训练与内部测试元数据。
